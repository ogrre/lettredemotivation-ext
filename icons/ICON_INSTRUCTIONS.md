# Extension icons

The extension uses the shared Lettre de Motivation brand mark: a mint rounded square with a dark four-point sparkle.

The manifest references these PNG files:

- `icon16.png` — 16×16 pixels;
- `icon48.png` — 48×48 pixels;
- `icon128.png` — 128×128 pixels.

`icon.svg` is the vector source. If the logo changes, export the three PNG sizes from that SVG and keep the filenames above unchanged.
