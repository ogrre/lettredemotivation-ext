# Privacy Policy for Cover Letter Generator Extension

**Last Updated: October 21, 2024**

## Introduction

Cover Letter Generator ("the Extension") is committed to protecting your privacy. This privacy policy explains how we handle your data.

## Data Collection and Usage

### Data Stored Locally

The Extension stores the following information **locally in your browser** using Chrome's storage API:

- **OpenAI API Key**: Your personal API key for accessing OpenAI services
- **Resume Text**: The extracted text content from your uploaded PDF resume
- **User Preferences**: Interface language and other configuration settings

### Important Privacy Notes

1. **No Remote Storage**: All your data is stored exclusively in your browser's local storage. We do not have access to your data, and it is never transmitted to our servers.

2. **Third-Party Services**: The Extension communicates only with:
   - **OpenAI API** (api.openai.com): To generate cover letters using your API key
   - The data sent to OpenAI includes: your resume text, job description, and generation parameters

3. **No Analytics or Tracking**: We do not collect, store, or transmit any analytics, usage statistics, or personal information.

4. **No User Accounts**: The Extension does not require user registration or authentication.

## Data Transmission

### OpenAI API Communication

When you generate a cover letter:
- Your resume text and the job description are sent to OpenAI's API
- Communication is encrypted via HTTPS
- Data is processed according to [OpenAI's Privacy Policy](https://openai.com/privacy)
- We recommend reviewing OpenAI's data usage policies

## Data Security

- Your API key and resume are stored using Chrome's secure storage API
- Data is only accessible to the Extension itself
- No data is shared with third parties (except OpenAI for generation purposes)

## User Rights

You have complete control over your data:
- **Access**: View your stored data in the Extension settings
- **Modification**: Update your API key, resume, and preferences at any time
- **Deletion**: Remove your data by:
  - Clearing individual items in the Extension settings
  - Uninstalling the Extension (removes all stored data)

## Children's Privacy

The Extension is not intended for users under the age of 13. We do not knowingly collect information from children.

## Permissions Explanation

The Extension requests the following permissions:

- **storage**: To save your API key, resume, and preferences locally
- **activeTab**: To interact with the current tab when generating letters
- **scripting**: To inject content scripts for enhanced functionality
- **host_permissions (api.openai.com)**: To communicate with OpenAI's API
