# Chrome Web Store Listing - Cover Letter Generator

## Basic Information

**Extension Name (English):**
Cover Letter Generator - AI Powered

**Extension Name (French Alternative):**
Lettre de Motivation - IA

**Short Description (132 characters max):**
Generate personalized cover letters instantly with AI. Works with Indeed, Welcome to the Jungle & all job sites. Dark mode UI.

**Detailed Description:**

Instantly create personalized, professional cover letters tailored to any job posting using the power of AI.

🎯 **KEY FEATURES**

✓ AI-Powered Generation - Uses OpenAI GPT-4o-mini to analyze your resume and job postings
✓ PDF Resume Import - Automatic text extraction from your CV
✓ Multilingual Support - Generate letters in French or English
✓ Dark Mode UI - Beautiful, minimalist interface inspired by modern design
✓ Character Control - Set custom length limits (200-10,000 characters)
✓ One-Click Copy - Instantly copy and paste into job applications
✓ Universal Compatibility - Works on Indeed, Welcome to the Jungle, LinkedIn, and all job boards
✓ Privacy-First - Your data stays local, only shared with OpenAI for generation

🚀 **HOW IT WORKS**

1. **Setup** - Add your OpenAI API key and upload your resume (one-time setup)
2. **Generate** - Click the extension icon, paste the job description
3. **Customize** - Choose language (FR/EN) and character count
4. **Copy** - Get your personalized cover letter in seconds

💡 **PERFECT FOR**

• Job seekers applying to multiple positions
• Professionals wanting to save time on applications
• Anyone who struggles with writing cover letters
• International job hunters (FR/EN support)

🔒 **PRIVACY & SECURITY**

• Your API key and resume are stored locally in your browser
• No data collection, no analytics, no tracking
• Open source code available on GitHub
• Only communicates with OpenAI API for letter generation

⚙️ **REQUIREMENTS**

You'll need an OpenAI API key (available at platform.openai.com). The extension uses the cost-effective GPT-4o-mini model.

🎨 **DESIGN**

Clean, modern dark mode interface with:
• Pure black background (#0a0a0a)
• Smooth animations
• Intuitive controls
• Professional aesthetic
